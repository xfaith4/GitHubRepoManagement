# Repository Standards

This folder holds baseline standards the tool can enforce across managed repositories.

## Current Standards

- Required root files:
  - `README.md`
  - `LICENSE`
  - `CONTRIBUTING.md`
  - `SECURITY.md`
  - `CODE_OF_CONDUCT.md`
  - `CHANGELOG.md`
- Required GitHub scaffolding:
  - `.github/CODEOWNERS`
  - `.github/PULL_REQUEST_TEMPLATE.md`
  - `.github/ISSUE_TEMPLATE/*`
  - `.github/workflows/ci-smoke.yml`

## Future Additions

- Standard label taxonomy.
- Branch protection policy checklist.
- Release/versioning conventions.
