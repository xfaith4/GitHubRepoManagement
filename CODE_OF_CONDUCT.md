# Code of Conduct

This project follows a professional and respectful collaboration standard.

## Expected Behavior

- Be respectful and technical in feedback.
- Focus on code, behavior, and evidence.
- Assume good intent and request clarification early.

## Unacceptable Behavior

- Harassment, personal attacks, or discrimination.
- Bad-faith review behavior or hostile communication.
- Sharing secrets or sensitive data in issues/PRs.

## Enforcement

Project maintainers may remove or restrict participation for violations.
